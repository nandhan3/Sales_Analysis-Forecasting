📊 Sales Analysis & Forecasting Using SQL
📌 Project Overview

A Retail Sales Data Analysis project using MySQL to analyze sales performance, identify trends, and generate business insights.

🎯 Objectives
    Analyze overall sales performance
    Identify top-performing stores and product families
    Analyze monthly and weekly sales trends
    Compare promotion vs non-promotion sales
    Analyze holiday vs non-holiday sales
    Calculate Year-over-Year (YoY) sales growth
    Calculate 3-month moving averages
🛠️ Tools & Technologies
    MySQL
    SQL
    MySQL Workbench
🔍 Analysis Performed
📈 Sales Trend Analysis

Analyzed monthly, weekly, and daily sales trends to identify high-performing periods.

🏪 Store Performance

Ranked stores based on total sales and analyzed average sales and record counts.

📦 Product Performance

Identified top product families and ranked them based on total sales.

🎯 Promotion Analysis

Compared sales performance between promoted and non-promoted products.

🎉 Holiday Analysis

Compared holiday and non-holiday sales across products and stores.

📊 Advanced SQL Analysis

Used Window Functions, RANK(), LAG(), and Moving Averages for advanced sales analysis.
